# Anime Tracker API 🌸

REST API сервис на Go для ведения личного списка аниме с автоматической фоновой синхронизацией новинок с Shikimori.

## 🚀 Что реализовано (Features)
* **REST API:** Обработка HTTP-запросов (GET, POST) с использованием стандартной библиотеки `net/http`.
* **База данных:** Хранение данных в PostgreSQL, безопасные SQL-запросы, защита от дубликатов.
* **Фоновый Воркер:** Использование Goroutines и Tickers для параллельного парсинга данных раз в сутки без остановки основного сервера.
* **Пагинация:** Продвинутая выдача данных (LIMIT, OFFSET) для работы с большими объемами.

## 🛠 Стек технологий
* **Язык:** Golang (Go 1.x)
* **База данных:** PostgreSQL
* **Взаимодействие:** REST, JSON
* **Инструменты:** Git, Go Modules
